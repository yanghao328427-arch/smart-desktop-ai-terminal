# 重建禁区

这些规则来自旧开发失败复盘。后续除非有新的日志证据，不再重复踩坑。

1. 不再把 ESP8266 HTTP 作为主链路。ESP8266 只保留为调试或备用方案。
2. 不再通过反复换 UART 引脚解决软件问题。先看协议、波特率、日志和 ACK。
3. 不再让用户无提示地反复喊唤醒词。正式测试必须先播“测试中，请说话”。
4. 不再把旧 HTTP pending 队列和实时 WebSocket 队列混用。
5. 不再让 SYN6288 承担 MP3/原声音频播放任务。
6. 不再只凭 RGB 灯判断系统状态。灯光必须与后端 session、ESP32S3 voice_state、STM32 ACK 一致。
7. RFID 先独立验收 UID，再并入主工程。
8. 语音链路先文本模拟，再音频上传，再唤醒/VAD；不要一次性叠满。
9. API Key 只能放环境变量或本地未提交配置，不写入固件、Markdown、前端或 STM32。
