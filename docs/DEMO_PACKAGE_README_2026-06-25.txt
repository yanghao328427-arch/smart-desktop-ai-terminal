智能桌面 AI 终端｜答辩演示包

使用方法：

1. STM32、ESP32S3 和传感器上电。
2. 双击“启动答辩演示.exe”。
3. 启动器会自动检测当前物理 Wi-Fi 和本机 IPv4；如需给 ESP32 换网，再填写或点击读取 Windows 已保存密钥。
4. 默认使用“阿里云直连”；只有现场确实启动了 8091 relay，才点击“填入本机 relay”。
5. 需要换网时确认串口号（默认 COM8），点击“写入 ESP32”。
6. 等待状态卡显示云端正常、设备在线、UART 正常、传感器新鲜。
7. 点击橙色“一键启动完整演示”。
8. 浏览器会自动打开，关键词监听会在后台启动，不会弹出命令行窗口。
9. 说“你好小鑫”开始语音演示。

包内文件：

- 启动答辩演示.exe：图形化一键启动器。
- runtime\语音监听器.exe：后台语音监听程序，请勿单独移动。
- 答辩演示讲稿.html：双击即可查看或打印。
- 智能桌面AI终端_答辩PPT_优化版_2026-06-25.pptx：答辩幻灯片。

注意：

- 默认麦克风编号为 1，可在启动器中修改或点击“查看麦克风”。
- 当前稳定语音入口是笔记本麦克风。
- 新版启动器启动语音前会自动关闭残留的旧监听，避免旧版“灵宝”继续占用麦克风。
- Wi-Fi 密钥默认遮罩，只在点击按钮时从 Windows 已保存配置读取；不会写入日志、讲稿或配置文件。
- 本机 IP 只用于 relay 备选，默认仍推荐 ESP32 直连阿里云。
- RFID 账号上下文可以保留，但实体刷卡授权只在最近一次真实刷卡后的 5 分钟内有效；过期后需重新刷卡或验证管理员密码。
- 启动器不会启用 ESP32S3 板载 WakeNet 实验分支。
- 如果设备未就绪，启动器会等待最多 3 分钟并在窗口内显示原因。
- 关闭启动器时，如果监听仍在运行，会询问是否一并停止。
