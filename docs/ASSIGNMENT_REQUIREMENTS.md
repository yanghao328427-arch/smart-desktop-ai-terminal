# 课程任务书要求整理

来源：`物联网工程综合课程设计（1）任务书` 和 `物联网工程综合课程设计（2）任务书`。

## 综合课设（1）

课程设计（1）偏硬件、感知、网络与平台全栈基础。

必须覆盖：

- 设计一个物联网全栈应用系统，包含感知层、网络层、平台层、应用层。
- 感知层至少两种传感器。
- 申请良好或优秀等级必须使用 RFID 读写器。
- 选择合适开发板和控制输出设备，形成感控闭环。
- 网络层支持有线或无线接入方式，例如 WiFi、BLE、Zigbee、NB-IoT、LoRa、5G。
- 智能场景既支持远程控制，也支持本地控制。
- 平台层可以使用云平台，也可以自行搭建服务器。
- 应用层要求 Web 应用和手机 App 或微信小程序。
- 完成硬件选型、嵌入式软件、平台设计、应用端软件、联动调试、报告、视频和答辩 PPT。

## 综合课设（2）

课程设计（2）偏平台层和应用层。

必须覆盖：

- 在课设（1）感知层、网络层、平台层基础上，重点完成平台层和应用层开发。
- 完成前后台应用端方案设计。
- 完成服务器端、PC 客户端、移动客户端或前端开发运行环境配置。
- 自行选择数据库、开发工具和开发语言。
- 完成联动调试、报告、成果视频和公开答辩。

## 本项目对应关系

| 课程要求 | 本项目实现 |
| --- | --- |
| 感知层 | STM32 采集温湿度、距离、声音；ESP32S3 接 RC522 RFID；可扩展摄像头/麦克风 |
| 至少两种传感器 | AHT20 温湿度、超声波距离、声音传感器、RFID |
| RFID | RC522 刷卡识别用户模式、锁屏/解锁、个性化配置 |
| 控制输出 | OLED、RGB、蜂鸣器、风扇、舵机、SYN6288 TTS |
| 网络层 | ESP32S3 通过 WiFi + WebSocket 接入后端；本地串口作为调试通道 |
| 平台层 | FastAPI 自建平台，管理设备状态、AI、工具调用、RFID 用户和诊断 |
| 应用层 | Web 控制台 + 移动端页面 |
| 智能增值 | AI 根据传感器、RFID 身份和历史上下文生成建议与动作 |
