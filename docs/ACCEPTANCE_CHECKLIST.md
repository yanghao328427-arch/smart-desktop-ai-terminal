# 答辩验收清单

- [ ] 四层架构图可讲清：感知层、网络层、平台层、应用层。
- [ ] 至少两种传感器实机数据进入后端。
- [ ] RFID 刷卡能识别用户或模式。
- [ ] Web 控制台可显示实时状态和 AI 回复。
- [ ] 移动端页面可打开并控制设备。
- [ ] 后端能生成动作并下发到 STM32。
- [ ] SYN6288 能播报 AI 回复。
- [ ] OLED 能显示状态。
- [ ] 风扇/蜂鸣器/舵机至少一个执行器完成闭环。
- [ ] ESP32S3 作为主联网节点，ESP8266 不作为主线依赖。
- [ ] 诊断页面能展示在线、UART、ACK、实时会话状态。
- [ ] 有成果视频脚本和可复现实验流程。
- [ ] 源码不包含 API Key。
